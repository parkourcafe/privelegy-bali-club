Дубли карточек — решение по каждой группе

Одно и то же место заведено в базе несколькими карточками. По каждой группе выберите одно из трёх: «Оставить одну» — выберите какую, остальные опубликованные карточки будут сняты с публикации; «Это разные места» — ничего не меняем; «Проверить» — нужен источник. Пока вы не скажете «да» по SQL, в базе ничего не меняется.
