## Диагноз T11 — это не баг сборки

Аудит 08.08 сформулировал T11 как «сборка не видит базу: 61 августовское место
отдаёт 404». Проверено по базе и коду 10.08:

- Все три контрольных слуга (`amavi-canggu-bali`, `kopiten`,
  `tsune-japanese-restaurant-sanur-by-wonderspace`) в базе `active` +
  `published`, созданы 04.08 — **и у всех пустые `why_its_here` и `best_for`**.
- Гейт публикации (`lib/publication.ts`) осознанно требует оба редакционных
  поля. Без них строка остаётся `review` → 404 + noindex. Это анти-дорвей
  правило проекта, оно работает как задумано.
- Масштаб: **110 строк** `active+published` без редакционных полей, из них
  **61 — августовский импорт** (источник `bali_privileges_club_partner_page`),
  49 — более ранние. По районам: Чангу 38 · Улувату 22 · Убуд 14 ·
  Кута-Легиан 12 · Санур 8 · остальные 16.

**Вывод: чинится редакционной партией, не кодом.** Заполняются два поля —
гейт открывается сам, деплой не нужен (маршрут `force-dynamic`, кэш 5 минут).

## Почему партия не написана прямо сейчас

Августовские записи пусты: имя, категория, район, адрес, ссылки — и всё.
По лестнице провенанса стандарта (`otherbali-venue-record-standard`) писать
`why_its_here`/`best_for` из этого нельзя — это ступень 3, выдумка.
Сетевая политика текущей среды не пускает ни на `baliprivilegesclub.com`,
ни на сайты заведений (egress blocked, проверено), поэтому ступень 1
недостижима отсюда. Это случай «блока C» из FIX_TZ: сборщик — вне этой среды.

## Как исполнить

1. **Сборщик** (любая среда с интернетом — Cowork, локальный чат) заполняет
   правые колонки `aug-import-editorial-worksheet.csv` по промпту
   `extraction-prompt.txt`. Дословно, без выдумок, с `source_url` и датой.
2. **Редакция** (репо-сессия): из собранного пишутся `why_its_here` (одна
   мысль — один факт), `best_for` (≤90 знаков, без «Visitors who want»),
   `not_for` — где факты дают основание. `last_verified_at` НЕ трогаем:
   ставится только `verified_at`-провенанс сборщика в notes.
3. **Заливка**: guarded SQL по шаблону
   `assets/venue-record-update-TEMPLATE.sql` (guard on empty), dry-run одной
   строки begin/rollback, ожидаемое число строк написано до прогона.
   Партиями: сначала 61 августовская, затем 49 старых тем же конвейером.

## Приёмка

- 61 строка получает оба поля → страницы открываются без деплоя;
- `/places` подхватывает их в течение 5 минут (TTL кэша);
- ни одно `best_for` не длиннее 90 знаков; ни одного нового нарушения F7;
- `publication_status` не меняется ни у одной строки (guardrail скилла).
